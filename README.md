# 🐾 PawSaath
### Connecting Pet Lovers, One Paw at a Time ❤️

PawSaath is a social networking platform designed exclusively for pet owners and animal lovers. The application allows users to share memorable moments with their pets, connect with a passionate community, and discover pet-related content in an engaging and user-friendly environment.

Developed during my **6-month Full Stack Development Internship**, this project provided hands-on experience in building scalable mobile applications, designing RESTful APIs, and collaborating within a development team.

# 📖 About the Project

PawSaath was created to build a community where pet owners can interact, share experiences, and celebrate their love for animals through photos, posts, and social engagement.

The application combines social networking features with a clean and intuitive mobile experience.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Aryan1396/pawsaath-app.git
```

Navigate to the project

```bash
cd pawsaath-app
```

Install dependencies

```bash
npm install
```

Start Metro Bundler

```bash
npm start
```

Run on Android

```bash
npm run android
```

Run on iOS

```bash
npm run ios
```
